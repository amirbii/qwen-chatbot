# Qwen Chat UI (Gradio)

یک چت‌بات سبک با **Gradio** و مدل **Qwen/Qwen2.5-1.5B-Instruct**.
سریع بالا میاد، کم‌هزینه، مناسب دمو و آزمایش.

## ✨ ویژگی‌ها

* رابط چت مینیمال با Gradio
* تاریخچه مکالمه و الگوی چت (Chat Template)
* تنظیمات نمونه‌گیری (temperature, top_p, repetition_penalty)
* قابل اجرا روی CPU/GPU 

## 🧱 پیش‌نیازها

* Python 3.10+
* اینترنت برای دانلود مدل از Hugging Face
* (اختیاری) GPU برای سرعت بهتر
